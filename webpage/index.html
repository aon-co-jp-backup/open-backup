open-backup

端末のフォルダを、あなた自身のGitHub非公開リポジトリへ自動でバックアップ(Windows / Linux / Android)

Automatically back up your folders to your own private GitHub repository (Windows / Linux / Android)

⚠ 保存先は必ず非公開(Private)に。公開リポジトリにすると、バックアップしたデータ(個人情報や認証情報を含む可能性があります)が世界中に見えます。このアプリは非公開リポジトリだけを自動で作り、保存先が公開になっていたら、データを送らずに止まります。あとから公開に変えると全データが公開されます。絶対に変えないでください。

Always keep the destination repository PRIVATE. If it is public, your backed-up data (which may include personal information or credentials) is visible to everyone. The app only creates private repositories and aborts without sending anything if the destination is public. If you switch it to public later, all your data becomes public — never do that.

使い方 / Quick start

  1. Windows / Linux: open-backup serve を実行し、ブラウザで http://127.0.0.1:4620/ui を開く。Android: アプリを開き、「すべてのファイルへのアクセス」を許可する。
    Windows / Linux: run open-backup serve and open the URL in a browser. Android: open the app and allow "All files access".
  2. 画面の「はじめての方へ」に従って、GitHub のアカウント(無料)・保存先の非公開リポジトリ・最小権限のトークンを用意し、トークンを貼り付ける。
    Follow the in-app "New here?" guide: a GitHub account (free), a private repository, a minimal-permission token — then paste the token.
  3. バックアップするフォルダを追加して「今すぐバックアップ」。以後は、変更を検知して自動で保存します。
    Add folders and press "Back up now"; afterwards changes are detected and saved automatically.

GitHub のアカウントが無い方へ / If you have no GitHub account

GitHub のアカウント(無料)を作ってください。アカウントの作成とメールアドレスの確認は、ご自身で GitHub の画面で行います。このアプリは代わりに作れません。

Please create a free GitHub account. You sign up and confirm your email yourself on GitHub; this app cannot do it for you.

  1. github.com/signup でアカウントを作る / create an account.
  2. github.com/new で、保存先の非公開(Private)リポジトリを作る。名前は、アプリの画面の「アカウント・保存先」に出ている名前(例 open-backup-PC名-0001)にする。末尾が -0002 のリポジトリも作っておくと、容量がいっぱいになったとき自動で切り替わります。
    Create a private repository named exactly as shown under "Account & destination" in the app (also create the -0002 one so it can switch automatically).
  3. Fine-grained トークンを、そのリポジトリだけに「Contents: Read and write」で作る(有効期限は短めに)。
    Create a fine-grained token limited to those repositories with "Contents: Read and write" only (short expiry).
  4. トークンをアプリの「GitHub にログイン」欄に貼り付ける。トークンは他人に見せないでください。
    Paste the token into the app's "Log in to GitHub" card. Never share it.

特長 / Features

  • 元のフォルダ構造のまま保存し、INDEX.md(拡張子による分類と索引)を自動で作ります。 Keeps your original folder layout and generates an INDEX.md (category index).
  • 容量が上限(既定 4GB)に近づくと、次のリポジトリへ自動で切り替えます。 Switches to the next repository automatically before one fills up.
  • git があれば git で、無い端末(Android)は GitHub API だけで、差分だけを送ります。 Uses git when available, otherwise only the GitHub API (Android), and uploads only what changed.
  • 通信するのは GitHub だけ。画面は端末の中(127.0.0.1)だけで動きます。トークンは OS の資格情報ストア、または Android のアプリ専用領域にだけ置きます。 It talks to GitHub only; the UI runs on 127.0.0.1; the token stays in the OS credential store or the Android app-private directory.

状態と制限 / Status and limits

  • アルファ版です。Windows(git の経路・GitHub API の経路)と Android エミュレーターでは保存まで通し確認しました。Android 実機でのログイン以降と、macOS の実行は未確認です。 Alpha. Verified end-to-end on Windows (git and GitHub API paths) and the Android emulator; login and later on a real Android device, and macOS, are not verified yet.
  • 1 ファイルは 40MB まで。GitHub は大容量のバックアップ向けではありません(リポジトリは数 GB まで)。 Files up to 40 MB; GitHub is not meant for huge backups (a few GB per repository).
