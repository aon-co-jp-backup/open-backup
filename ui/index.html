open-backup

端末のデータを、あなたのGitHub非公開リポジトリへ自動バックアップ / Auto-backup to your private GitHub repository

エンジンに接続できません。open-backup serve を起動してください。 / Cannot reach the engine. Start `open-backup serve`.
⚠ 保存先のGitHubリポジトリは必ず非公開(Private)にしてください。公開すると全データが世界中に見えます。 / Keep the GitHub repository PRIVATE. Making it public exposes all your data.

GitHub にログイン / Log in to GitHub

最小権限のトークン(保存先の非公開リポジトリ1つだけに「Contents: 読み書き」)を、ご自身で作って貼り付けてください。作り方は README を参照。 / Create a minimal-permission token yourself (Contents: read & write on the one private repository) and paste it here. See the README.

はじめての方へ(GitHub のアカウントが無い方も) / New here? (no GitHub account yet)
  1. GitHub のアカウントが無い場合は、無料で作ります。アカウントの作成とメールアドレスの確認は、ご自身で GitHub の画面で行います(このアプリは代わりに作れません)。 / If you have no GitHub account, create a free one. You sign up and confirm your email yourself on GitHub; this app cannot do it for you. github.com/signup
  2. 保存先の非公開(Private)リポジトリを作ります。名前は、下の「アカウント・保存先」に出ている名前にしてください: / Create a private repository named exactly as shown under "Account & destination" below: (容量がいっぱいになったとき自動で切り替えるため、末尾が -0002 のリポジトリも作っておくと安心です / also create the -0002 one so it can switch automatically when the first fills up) github.com/new
  3. そのリポジトリだけに「Contents: 読み書き(Read and write)」を許可した Fine-grained トークンを作ります(有効期限は短めに)。 / Create a fine-grained token limited to those repositories with "Contents: Read and write" only (short expiry). github.com/settings/personal-access-tokens/new
  4. 作ったトークンを上の欄に貼り付けて「ログイン」。トークンは他人に見せないでください。 / Paste the token above and press Log in. Never share it.

GitHub は大容量のバックアップ向けではありません。1ファイルは 100MB(このアプリは 40MB)まで、リポジトリ全体は数GBまでが目安です。 / GitHub is not meant for huge backups: files up to 100 MB (this app: 40 MB) and a few GB per repository.
